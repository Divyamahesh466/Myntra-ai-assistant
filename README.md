# 🛍️ Myntra AI Fashion Assistant ✨

An AI-powered **Fashion & Shopping Assistant** built using Python and Streamlit. The application helps users discover fashion products, get personalized recommendations, manage their wishlist and shopping bag, and explore products through an interactive and modern shopping interface.

---

##  Project Overview

**Myntra AI Fashion Assistant** is a smart fashion shopping application designed to provide users with an interactive and personalized shopping experience.

The project combines **Python, Machine Learning, NLP, Pandas, Scikit-learn, and Streamlit** to create an intelligent fashion recommendation and shopping assistant.

The application provides a modern dashboard with features such as product search, recommendations, wishlist management, shopping bag, and an AI fashion assistant.

## ⚙️ Installation

### 1. Clone the repository

```bash
git clone https://github.com/YOUR-USERNAME/Myntra-AI-Fashion-Assistant.git
```

### 2. Open the project folder

```bash
cd Myntra-AI-Fashion-Assistant
```

### 3. Install the required libraries

```bash
pip install -r requirements.txt
```

## 🚀 Run the Application

Run the Streamlit application using:

```bash

```

After running the command, Streamlit will provide a local URL.

Open the URL in your browser to access the application.

## 📊 Dataset

The application uses a fashion product dataset containing product-related information used for product search and recommendation.

**Dataset:** `Fashion Dataset.csv`

The dataset is processed using **Pandas** and used by the recommendation system to identify relevant fashion products.

---

## 🧠 Recommendation Approach

The recommendation component uses text-based product information to identify products that are similar to the user's search or requirements.

The general workflow is:

```text
User Input
     ↓
Text Processing
     ↓
Feature Extraction
     ↓
Similarity Calculation
     ↓
Product Ranking
     ↓
Recommended Products
```

The project uses **TF-IDF and cosine similarity** for text-based similarity and recommendation.
